# LegalityTag

Petit badge d'état, 12px, `radius-sm` : teinté (`--legal`, `color-accent-800` et texte `color-accent-100`), contour accent (`--illegal`) ou contour neutre (`--unknown`).

Né pour la légalité d'un deck, c'est le seul badge de l'application ; le Lot 12 peut le reprendre pour « Administrateur » ou « Cet appareil » plutôt que de créer une classe.

Source : `frontend/src/index.css` (`.legality-tag`).
