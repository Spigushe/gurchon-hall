# Stepper

Quantité avec `−` et `+` : boutons de 44px bordés, valeur en 18px tabulaire au centre.

`+` en accent (`stepper__btn--accent`), `−` neutre ; `.stepper--form` agrandit le tout (48px, valeur en 30px) dans une feuille. Sans usage au Lot 12.

Source : `frontend/src/components/Stepper.tsx`, `index.css` (`.stepper*`).
