# Seg

Choix exclusif à deux options, en grille de deux colonnes bordée `color-divider`, 42px de haut.

L'option cochée prend un contour intérieur et le texte en accent, en 500. Natif : des `input type="radio"` masqués dans des `label.seg__option`, le tout dans un `fieldset.seg-field` avec sa `legend`.

Source : `frontend/src/index.css` (`.seg-field`, `.seg`, `.seg__option`).
