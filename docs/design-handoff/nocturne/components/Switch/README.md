# Switch

Interrupteur dans une ligne à libellé : texte à gauche, `.switch` à droite, filets dessus et dessous.

Le `.switch` est un `input type="checkbox"` restylé (46 × 28px) ; allumé, rail `color-accent-800` et bouton `color-accent-200`. Toute la ligne est cliquable (`label.switch-row`).

Source : `frontend/src/components/Switch.tsx`, `index.css` (`.switch-row`, `.switch`).
