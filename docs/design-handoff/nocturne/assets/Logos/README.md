# Logos

L'icône de l'application, versée telle quelle depuis `frontend/public/` : une lune rouge à deux crocs sur un fond presque noir.

- `pwa-512.png` : icône 512 × 512 du manifeste.
- `pwa-maskable-512.png` : variante masquable (zone de sécurité pour les formes d'Android).
- `apple-touch-icon.png` : 180 × 180 pour iOS.

Le rouge (#ba1e3e) et le fond (#1a0410) sont ceux de l'image, pas des tokens : ils ne se reprennent pas dans l'interface. Pas de logotype dessiné : dans l'application, la marque s'écrit en texte, « Gurchon Hall » ou « GURCHON HALL » en kicker. Aucun SVG source n'existe dans le dépôt.
